## 📌 Executive Summary

This repository contains the deliverables for **Task 3: Secure Coding Review** of the **CodeAlpha Internship**. 

The subject application, **MiniBlog**, is a lightweight Flask-based web application with SQLite database integration. The objective of this project was to perform a static application security review, identify critical security vulnerabilities against industry standards (OWASP Top 10), document findings, and deliver a fully remediated, production-hardened version of the application (`app_secure.py`).
